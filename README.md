# 酒搭 · JIU DA

### 今晚，一起喝一杯。

**[打开酒搭 → https://jiuda-demo.pages.dev/](https://jiuda-demo.pages.dev/)**

一个面向成年人的同城约酒社区。找个聊得来的酒友，去那家收藏了很久、却一直没人陪你去的酒吧。

## 为什么做酒搭

我给自己写了一个很宏大的理由：

> 为了解决年轻人的性压抑问题，探索生活的真谛，传播真善美，让世界变得更美好，我制作了这个网站。

说得接地气一点：想出门的时候有人回应，想聊天的时候有人接话，想喝一杯的时候，不用翻遍通讯录。

我们不缺社交软件，偶尔缺的只是一个“今晚有空，一起吗”的人。酒搭想把这句开场白变得简单一点。至于能不能从一杯酒聊成朋友、聊出默契，交给彼此慢慢了解。

## 在这里可以做什么

- **找同城酒友**：按省、市找到同城的约酒计划，还可以筛选区县。
- **发一句“我缺个搭子”**：写下想去的酒吧、时间、氛围和还缺几位，等同城的人回应。
- **同意邀约，再开始聊天**：同城在线用户发出邀约，双方同意后开启私聊，一起商量见面安排。
- **分享微醺日常**：发布照片和动态，点赞、评论，先认识一个人，再决定要不要一起出门。
- **带着自己的标签出场**：站主手动填写颜值评分和级别，审核通过后会在资料和约酒卡片中公开展示。

## 怎么开始

1. [打开酒搭](https://jiuda-demo.pages.dev/)，不用注册也可以先逛逛。
2. 想发布约酒时，设置账号密码、填写资料，并提交一张审核照片。
3. 审核照片仅站主可见；注册时需同意人工评级公开展示。
4. 站主审核通过并填写评分、级别后，就可以发布、邀约和聊天。

照片评分只是站主的主观评价，不代表身份认证，也不定义一个人的价值。

## 喝得开心，也相处得舒服

仅限 **18 岁及以上成年人**。尊重彼此的意愿和边界，不骚扰、不劝酒；初次见面选公共场所，喝酒不开车，平安回家。
